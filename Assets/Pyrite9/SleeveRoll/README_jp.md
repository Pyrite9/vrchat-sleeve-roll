# Pyrite9 Sleeve Roll

バージョン 0.1.0 (2026-11-07)

VRChat アバター用の袖まくりギミックです。プレハブをアバターに入れて袖のある衣装を選ぶだけで、ビルド時にその衣装のメッシュから「まくった袖」の形を計算して入れます。
Expression Menu のトグルをオンにすると両袖がまくれ上がり、他の人にもそのまま見えます。このパッケージにはシェイプキーもメッシュのデータも入っていないので、袖のある衣装ならどれでも使えます。

English: `README_en.md` / 한국어: `README_ko.md` / 利用規約: `LICENSE.txt`

## 機能

- Expression Menu のトグルで両袖が 0.2 秒でまくれ上がる — 他の人にも見える（同期 1 bit）
- まくれた形はビルド時に、あなたが持っている衣装から計算 — 肌を測って布が腕に埋まらないようにし、元の布の厚みとゆとりの一部を残し、たまった所にしわを入れる
- 衣装が袖の下の腕を shrink している場合は、まくっている間 shrink を解除する — まくった袖口の中をのぞいても細い腕が見えない
- 手首を曲げてもひねっても、まくった袖口はそのまま（手首の補助ボーン）
- 袖に PhysBone がある衣装（萌え袖）は普段どおり揺れ、まくっている間だけ動かない
- 重ね着（ジャケットの下のシャツなど）は複数選ぶと、内側から順にまくり、外側の袖を内側のまくった袖口の上に重ねる
- シーンも衣装のメッシュファイルも変わらない — 変わるのはビルド用のコピーだけ
- インスペクターで衣装の候補をボタンで選び、袖口の位置・すき間・しわをゲージで調整し、袖口の来る所を Scene ビューの金色の輪ですぐ確認できる
- まくった袖をビルドせずに Scene ビューで確認できる（**まくる位置** の **プレビュー**）— 計算はビルドと同じ

## 必要なもの

- Unity 2022.3（VRChat）
- VRChat SDK – Avatars 3.10 以上
- Modular Avatar
- NDMF（Non-Destructive Modular Framework）

確認した環境：Unity 2022.3.22f1、VRChat SDK Avatars 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8。
これより古いバージョンとプレビュー版（alpha・beta）は確認していません。

- ヒューマノイドのアバターのみ（肘・手首の位置を Humanoid のボーンから探します）。
- 試した衣装：Salt の標準パーカー、Kipfel のシャツ、Milfy のカーディガン、輝夜（Kaguya）のカーディガンとセーラー服の重ね着。**PC で確認しました。** Android / Quest 版は確認していません。重ね着はこの 1 組で確認しました。
- PhysBone の袖：手のボーンの下に PhysBone がある衣装 1 着（輝夜のカーディガン）で、Unity の Play と VRChat 内で確認しました（他の人の画面、その人のインスタンス再入室を含む）。

## 導入

1. **必要なパッケージを入れます。** VCC / ALCOM でアバターのプロジェクトを「管理」（Manage Project）で開き、**Modular Avatar** を追加します。
   NDMF は Modular Avatar と一緒に自動で入ります。安定版（プレビューではないバージョン）を使ってください。
2. **このパッケージをインポートします。** `.unitypackage` をダブルクリック（または Unity の `Assets > Import Package > Custom Package…`）し、すべてチェックしたまま **Import** を押します。ファイルは `Assets/Pyrite9/SleeveRoll/` に入ります。

## 使い方

1. Project ウィンドウで `Assets/Pyrite9/SleeveRoll/` を開き、`Pyrite9 Sleeve Roll.prefab` を Hierarchy のアバター（VRC Avatar Descriptor が付いたオブジェクト）にドラッグします。アバターの直下に置いてください。**アバターの外にあると何も起きません。**
   - プレハブを Unpack しないでください（アップデートが反映されません）。
2. インスペクターの最初の区画（基本）で：
   - **Menu language**（`EN` / `日本語` / `한국어`）で **日本語** を選ぶと、ゲーム内のメニュー名とインスペクターが日本語になります（初期値 EN）。
   - **衣装**：このアバターの袖のある衣装がボタンで出ます — まくる衣装を押してください（もう一度押すと外れます）。重ね着は複数押します。ボタンにない場合はボタンの下の **ボタンにない衣装** 欄に衣装の Skinned Mesh Renderer をドラッグします。体ではなく **衣装** のメッシュを選んでください。
   - **袖**：両方（初期値）/ 左 / 右。
3. （任意）**まくる位置**・**まくった袖の形** の区画で、袖口の位置・肌とのすき間・袖の太さ・しわを合わせます。Scene ビューの金色の輪が袖口の来る所です。**プレビュー** を **ON** にすると、まくった袖を見ながら調整できます。シーンやアップロードには影響しません。ゲージをダブルクリックすると初期値に戻ります。
4. 試してみます：
   - Unity で **Play** を押すと、まくった袖がビルドされ、インスペクターの **最後のビルド** が表示されます（Play を止めた後）。Play 中は Gesture Manager などで Expression Menu のトグルをオンにしてみてください。
   - `VRChat SDK > Show Control Panel > Builder` → **Build & Test** の後、VRChat でテストアバターに着替えます。Build & Test は自分の画面だけです — 他の人からの見え方は（Private で）アップロードした後に確認できます。
5. 結果を確認します。正常なら **最後のビルド** に衣装名と左右それぞれの袖口の位置（例：`0.30 まで`）、**警告：なし** が出ます。重ね着は内側から順に並び、外側の衣装には `○○ の上` が付きます。
   - 警告は Console にも `[Pyrite9 Sleeve Roll]` で始まる黄色い行で出ます — 「トラブルシューティング」を見てください。詳しくはプロジェクトフォルダーの `Logs/Pyrite9_SleeveRoll_build.txt` に書かれます。

重ね着（シャツの上のジャケットなど）は 1 つの Sleeve Roll で両方を選んでください。内側・外側はビルドが前腕の太さで決めます（細い方が内側）。衣装ごとに設定を変えたいときは Sleeve Roll をもう 1 つ入れて分けて選んでもかまいません — それでも重なりは合わせられ、1 つのトグルで一緒にまくれます。

## Expression Menu

| メニュー | 動作 |
|---|---|
| `袖まくり` | オンで両袖をまくり、オフで下ろします（保存しない、他の人にも見える、初期値オフ） |

メニュー名はメニュー言語によって `Sleeve Roll` / `袖まくり` / `소매 걷기` で、インスペクターの **メニュー名** で変えられます。
**メニュー** をオフにするとメニューは入りません。それでも同期 Bool パラメーター `Pyrite9/SleeveRoll/Hold` は作られるので、自分で作ったメニューやコンタクトからこの名前でオン・オフできます。

## パフォーマンス

| 項目 | 増えるもの |
|---|---|
| BlendShape | 衣装に 2（`SleeveUp_L`・`SleeveUp_R`）、衣装の下の腕を shrink している体のメッシュに 2（`SleeveRoll_Unhide_L/R` — shrink がある場合のみ） |
| ボーン | 2（手首の補助ボーン `SleeveRoll_Wrist_L/R`）、維持する袖の PhysBone のうち布が乗るボーンごとに 1（`SleeveRoll_Shadow_…`） |
| Constraint | VRC Rotation Constraint 2、維持する袖の PhysBone のうち布が乗るボーンごとに 1 |
| FX レイヤー | 1 |
| 同期パラメーター | 1 bit（アバターの Sleeve Roll 全部で共通） |
| メニューアイコン | テクスチャ 1 枚、256×256（メニューのトグルを使うときだけ） |

メッシュ・マテリアルは増えません。テクスチャもメニューアイコンのほかは増えません。袖の PhysBone の数も増えません（既存のものがそのまま動きます）。

## 設定（Sleeve Roll コンポーネント）

- **基本**：Menu Language・Garments（衣装、候補ボタン — 複数可、ボタンにない衣装の欄）・Sleeves（両方 / 左 / 右）。
- **メニュー**：Install Menu（+ Menu Name）。アバターに Sleeve Roll が複数あれば、衣装を選んだ最初の Sleeve Roll の値だけを使います。
- **まくる位置**（0 = 手首・1 = 肘、大きいほど上までまくる）：Roll To（袖口の位置、初期値 0.30。ゲージの黄色（0.45〜）・オレンジ（0.60〜）の範囲は不自然になることがあるので **プレビュー** で確認）・Unhide When Rolled（まくっている間 shrink を解除、オフなら shrink を保ち shrink された腕が見える手前で止まる。オフにした場合はインゲームで袖の中を必ず確認）。
- **まくった袖の形**（mm、袖の太さは 0〜1 の割合）：Margin（肌とのすき間）・Looseness（袖の太さ）・Fold Amplitude（しわの深さ）・Fold Length（しわの間隔）・Start At（動き始め、0 = 手首・1 = 肘、これより肘側は動かない。初期値 0.75。細かい調整用：形が変わるので **プレビュー** で試す。肘に近づけすぎると袖が縮んだように見え、衣装によっては肘を曲げたときに肌が突き抜けるので、インゲームで確認）。
- **詳細**：Wrist Proxy（まくった袖口を固定）・Body Meshes（肌を測るメッシュ、空なら自動）。
- **最後のビルド**：そのアバターの最後のビルド結果（衣装ごと — 内側から、外側の衣装はどの衣装の上か — 左右ごとの袖口の位置、shrink の境目で止まったか、shrink を解除した頂点の数）と警告、ビルドログ・README ボタン。
- **バージョン**：1 日 1 回 GitHub に最新版を問い合わせ、新しいバージョンがあればお知らせします（下の「補足」）。
- **更新履歴**：この版の変更内容（この README から読み込み）。

## トラブルシューティング

Console の警告は英語で出ます。インスペクターの **最後のビルド** にも同じ英語の文が出ます。

| メッセージまたは症状 | すること |
|---|---|
| `Not a humanoid avatar — Sleeve Roll not built` | アバターの Rig が Humanoid か確認してください。ヒューマノイドのみ対応です。 |
| `no garment picked — this Sleeve Roll does nothing` | インスペクターの **衣装** で袖のある衣装を選んでください。 |
| `the sleeve (… mm) is thinner than the skin (… mm) — the picked mesh looks like a body` | 体のメッシュを選んでいます。衣装のメッシュを選んでください。 |
| `the garment is not weighted to the forearm bone` | この衣装の袖が前腕のボーンに付いていません（半袖など）。まくれない衣装です。 |
| `the sleeve is already shorter than Roll To` | 袖がすでに袖口の位置より短いです。**袖口の位置** を上げてください（肘側へ）。 |
| `the body mesh has forearm skin only from t=… (cut away under the outfit)` | 体のメッシュが衣装の下の前腕を切り取ったモデルです。前腕のある体のメッシュに変えるとまくれます。 |
| `no skin (body) mesh found on the forearm` | 肌を測る体が見つかりません。**詳細 > Body Meshes** に体のメッシュを入れてください。 |
| `an MA Shape Changer in Delete mode removes vertices at build` | この体のメッシュはビルド時に頂点を消します。まくった所に穴が見えたら、その Shape Changer を Set モードにしてください。 |
| まくった布から肌が透ける | **まくった袖の形 > 肌とのすき間** を上げてください。 |
| まくった袖が太すぎる・細すぎる | **袖の太さ** を調整してください（左端で腕にぴったり）。 |
| 重ね着で内側の布が外側から透ける | 両方の衣装を選んだか確認してください（選ばない衣装はまくられずそのまま）。外側の衣装の **肌とのすき間** を少し上げてもかまいません。 |
| `this sleeve's PhysBone stops moving (…)` | この袖の PhysBone を安全に維持できないため（理由は括弧内）、袖は物理なしで手に付いていきます。まくることはできます。物理を残すには括弧内の原因を取り除いてください。 |
| `a PhysBone on the forearm (…) holds this sleeve and cannot be held still while rolled (…)` | この袖はまくれません。物理を止めておけないためです。2 つ目の括弧内の原因を取り除いてください。 |
| `a PhysBone under the upper arm (…) holds this sleeve down to t=… — it cannot be rolled` | 上腕の PhysBone が袖口まで支えているため、まくれない衣装です。 |
| まくり始めに袖が一度動く | 正常です。まくった形は PhysBone の静止姿勢から計算するので、垂れた袖がその姿勢に戻ります。下ろすとまた揺れます。 |
| まくった袖口が手首と一緒に曲がる | **詳細 > Wrist Proxy** がオンか確認してください。 |
| 袖口が腕より下に垂れた衣装（片側にずり落ちた袖など） | 袖の先が開いていれば、ビルド時に自動で補正します。ビルドログに `normalized` と出ます。確認した衣装は Foxy シリーズのみです。袖の先が閉じた袖、袖口が離れた袖、大きな別パーツ（リボンなど）が付いた袖、上側に切れ目がある袖は、補正されないか形が崩れることがあります。 |

## 更新・削除

- **更新：** 新しいパッケージを上から重ねてインポートします（すべてチェックしたまま Import）。設定はシーンの Sleeve Roll オブジェクトに保存されているので、そのまま残ります。`Assets/Pyrite9/SleeveRoll/` の中のファイルは編集しないでください — 更新で上書きされます。
- **アバターから外す：** アバターの Sleeve Roll オブジェクトを削除します。
- **プロジェクトから消す：** 先にアバターから外し、その後 `Assets/Pyrite9/SleeveRoll/` フォルダーを削除します。
- インスペクターの更新履歴はこの README から読み込みます — README ファイルはパッケージのフォルダーにそのまま置いてください。

## 補足

- まくれた形はビルドのたびにその衣装のメッシュから計算し直します。衣装を変えたり直したりしても、もう一度ビルドすれば合います。
- 袖の PhysBone はビルド時に調べ、まくっている間止めておいても安全なときだけ維持します。他のボーンも動かす、Is Animated がオン、Max Stretch・Max Squish を使用、Avatar Optimizer の Merge PhysBone で使用、その PhysBone やボーンを動かす別のアニメーションがある、静止姿勢がメッシュと違う — いずれかに当てはまると維持せず警告します。維持した数は **最後のビルド** に出ます。
- 衣装に独自の半袖シェイプキーがあると、一緒にオンになることがあります。試した衣装（Kipfel のシャツ・Milfy のカーディガン）では重なっても大きく崩れませんでした。
- FX レイヤーはアバターの Write Defaults 設定に合わせます（Modular Avatar「Match Avatar Write Defaults」）。Action・Base・Gesture レイヤーは使いません。
- Unity エディターで Sleeve Roll のインスペクターを開くと、1 日 1 回 GitHub（`api.github.com`）にこのパッケージの最新版を問い合わせます。個人の情報は送信しません。バージョンの文字を押すとすぐにもう一度確認します。
