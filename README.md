プレハブをアバターに入れて袖のある衣装を選ぶだけ。ビルド時にその衣装のメッシュからまくった袖の形を計算します。Expression Menu のトグルで両袖がまくれ上がり、他の人にも見えます  
Drop the prefab into an avatar and pick the sleeved garment. The rolled shape is worked out from that garment's mesh when you build. An Expression Menu toggle rolls both sleeves up, and others see it too.  
프리팹을 아바타에 넣고 소매 달린 옷을 고르면 됩니다. 걷힌 모양은 빌드할 때 그 옷 메시로 계산합니다. Expression Menu 토글로 양 소매가 걷혀 올라가고, 남에게도 보입니다

このパッケージにシェイプキーやメッシュのデータは入っていません  
This package contains no shape key or mesh data.  
이 패키지에는 셰이프키나 메시 데이터가 들어 있지 않습니다

## Requirements

- Unity 2022.3 (VRChat)
- VRChat SDK – Avatars 3.10 or later
- Modular Avatar / NDMF
- Humanoid avatar with a sleeved garment

Tested with Unity 2022.3.22f1, VRChat SDK Avatars 3.10.5, Modular Avatar 1.18.7, NDMF 1.14.8.

## Install

1. Install Modular Avatar with VCC / ALCOM
2. Import the `.unitypackage` from [Releases](../../releases/latest)
3. Put `Pyrite9 Sleeve Roll.prefab` directly under your avatar and press the garment's button in the inspector
4. Upload as usual
